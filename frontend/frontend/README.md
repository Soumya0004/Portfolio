# Portfolio

![React](https://img.shields.io/badge/-React-blue?logo=react&logoColor=white)

## Description

A responsive personal portfolio built with React, showcasing projects, skills, and contact information.

## Tech Stack

- React
- Vite
- Tailwind CSS

## Key Dependencies


## Run Locally

```sh
npm install
npm run dev
```

## Available Commands

- `npm run dev` - Start the development server.
- `npm run build` - Build the production site.
- `npm run lint` - Run ESLint.
- `npm run preview` - Preview the production build.
